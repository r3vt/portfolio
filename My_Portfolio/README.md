# Mojtaba Alhaj — Personal Portfolio

## Files
- `index.html` — website structure and content
- `style.css` — colors, layout, and responsive styling

## Before submitting
1. Replace `YOUR_EMAIL@example.com` in `index.html` with your email address.
2. If you have a suitable profile photo, you can replace the initials avatar with an image.
3. Update the Projects section so it accurately reflects work you have completed.
4. Open `index.html` in a browser and take screenshots for the assignment's Output Screenshots section.

## Publish with GitHub Pages
1. Sign in to GitHub and create a new public repository, for example `personal-portfolio`.
2. Upload `index.html` and `style.css` to the repository's root.
3. Open **Settings → Pages**.
4. Under Build and deployment, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
5. Wait for GitHub Pages to publish the site. Copy the published URL into your assignment.

The site uses Google Fonts when an internet connection is available; system fonts will be used if they are not.
